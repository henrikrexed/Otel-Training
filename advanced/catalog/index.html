    Catalog — extra exercises (choose your path)

    Beyond the linear Step 0–7 arc, the catalog holds self-contained exercises — grouped by theme — that a facilitator can drop in for depth or variety. Each follows the same teaching shape as the main arc: ① Problem → ② Understand the change → ③ opencode prompt ladder → ④ Review & apply → ⑤ Verify (DQL), with a planted labs/advanced/… reference answer.

    Themes: A = traces/instrumentation · B = metrics/collector · C = Dynatrace automation. Pick by the time you have and the muscle you want to build:

    Exercise Theme Time Difficulty opencode skill You will…
    A1 — Fix a broken distributed trace traces 25m med otel-instrumentation Restore context propagation across a dropped async hop so the slots → scoring trace reconnects end-to-end.
    A2 — Log ↔ trace correlation traces / logs 20m med otel-instrumentation Inject trace_id / span_id into slots logs so Dynatrace links each log line to its span — and pivots between them.
    A3 — Multi-language instrumentation traces 25m med otel-instrumentation Port the Step-1 span pattern to a 2nd SDK (Python roulette), proving the casino.* contract crosses languages.
    B1 — RED metrics from spans metrics / collector 20m med otel-collector Add the spanmetrics connector to the gateway and chart Rate / Errors / Duration — no app-code change.
    B3 — Drop noise (filter processor) metrics / collector 15m easy otel-collector Drop health-check / /metrics spans at the gateway — verify the ingest drop with no signal loss.
    C1 — Build a dashboard via dtctl Dynatrace automation 20m med dtctl Turn your Step-2 business metrics into a live, version-controlled Dynatrace dashboard — as code.

    Prerequisites

    All assume the base environment is up and Step 0 — Warmup has installed the opencode skills (opencode debug skill lists otel-* and dtctl). A2 and A3 build on the span pattern from Step 1; C1 builds on the metrics from Step 2 and the RED metrics from B1.
